# 五篇真实论文摘要对照

本轮测试选取 5 篇 CoRL 2025 论文：EquiBot、Sparsh、ManiWAV、PoliFormer 和 OKAMI。作者摘要来自各自的 PMLR 官方页面，Super Writer 版本由正文 PDF 第 2 页起整理出的证据包独立生成，生成上下文没有提供作者摘要或 PMLR 摘要页面。

逐篇对照见 [`results.json`](results.json)。每篇包含：

- 作者摘要的中文忠实概述、原文链接和原摘要词数；
- Super Writer 独立英文摘要的中文翻译；
- 保留点、改进点、遗漏或风险；
- 基于正文证据的事实核查结果。

## 测试边界

生成版本的英文词数分别为 145、209、147、141、143，与作者摘要长度保持在同一量级。写作者只接收正文证据、贡献记录、关键解释关系和限制，不接收原摘要，因此这不是“看着原文润色”的任务。

作者一侧使用“中文概述”而不是在仓库中复制原摘要全文；原文可通过每篇的 PMLR 链接查看。中文不是简单逐词替换，而是保持原作者的研究问题、方法、结果和边界的忠实转述。

## 快速结论

1. **机制解释更清楚了。** EquiBot 的等变结构如何支持变换场景泛化，OKAMI 的物体条件重定向如何摆脱固定坐标回放，Super Writer 版本都比作者摘要更显式。
2. **证据边界更完整了。** Sparsh、ManiWAV 和 PoliFormer 版本补充了训练/留出设置、评测对象和限制，使数字更容易被审计。
3. **但不一定更适合投稿摘要。** ManiWAV、PoliFormer 和 OKAMI 的版本加入了较多实验数字，虽然更可核查，却也更拥挤。作者摘要在信息选择和收束上更像最终投稿文本。
4. **这不是总体质量胜负实验。** 本轮只有一个生成版本、5 篇论文、没有人类盲评，也没有把作者摘要作为写作者输入。结果用于诊断系统是否学到了组织关系，不用于宣称优于原论文。

## 逐篇观察

### EquiBot

新版本把“等变性”从性质标签写成了处理链：规范化输入、等变条件与去噪、动作还原，并把扩散模型和多模态长时程行为联系起来。代价是实验细节变多，作者原摘要的简洁收束更适合摘要场景。

### Sparsh

新版本明确了冻结编码器、探针训练、减少标注和留出压头/轨迹的关系，因此读者能理解“表示可迁移”是如何被测量的。它有意没有把正文中不同聚合口径的 95.1% 和 98.75% 混在一起，这是事实保守性提升，但也让结果句不如作者摘要醒目。

### ManiWAV

新版本清楚区分接触音频的作用、噪声增强的作用和子步骤成功率，避免把每个百分比都叫作整体任务成功率。问题是指标太多，作者摘要的“设备/接口/四类任务/未见环境”组织更紧凑。

### PoliFormer

新版本把 KV cache、并行 rollout、训练规模和未见房屋迁移连接起来，比“Transformer + 大规模 RL”更有解释力；同时保留深度缺失、记忆退化、本体分开训练和算力成本。它的技术细节密度已经接近 Results 摘要，需要根据会议字数继续压缩。

### OKAMI

新版本明确“物体定位与关系变换把一次演示变成新位置的计划”，并区分直接模仿成功率和后续 ACT 训练结果。这是本轮最接近优秀方法摘要组织的一篇，但仍然塞入了过多任务级数字和限制。

## 复现

当前目录中的源 PDF、正文证据包、原摘要临时文件和写作者原始输出保存在本机 `/tmp/super-writer-abstract5/`，没有把第三方 PDF 或原摘要全文提交到仓库。仓库 artifact 只保存了来源链接、中文概述、生成版本翻译和诊断结果。

本轮的主要结论是：Super Writer 已经能更稳定地写出“操作/对象/结果/边界”的关系，但还需要一个更强的摘要信息预算器，自动决定哪些正文证据值得进入摘要，避免把可审计性变成数字堆积。
