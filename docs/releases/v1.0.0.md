# Super Writer 1.0.0

First standalone open-source release of the writing skill previously maintained
as `paper-spine` inside Super Skill Team. The GitHub repository is `super_writer`;
the installable skill ID is `super-writer`.

## Included

- PaperSpine V4 research, contribution, motivation, citation, writing, review,
  translation, and document-delivery playbooks, with 25 Python tool files.
- A portable entrypoint, current-terminal intake launchers, and standalone update
  instructions; legacy project config and output filenames are retained.
- Chinese and English documentation, a workflow diagram, task prompts, and a
  synthetic example with source materials, PDF, Word, and rendered preview.
- Explicit provenance, upstream MIT attribution, capabilities, and activation cases.
- Offline installation and a reproducible release ZIP with per-file checksums.
- Cross-platform CI and distribution/installation regressions.
- Citation-query privacy fixes, global preference isolation, and font-only
  document repair, with regressions for each boundary.

## Validation

The extraction passed the inherited 11-case smoke suite. Local distribution,
portable-usage, and release-safety tests ran on Python 3.14; the PowerShell-only
check is covered by Windows CI and skipped when PowerShell is unavailable locally.
The public example compiled with pdfLaTeX and its converted Word passed the title,
text, and font guard. Two independent bounded writing exercises checked evidence
limits and source-instruction handling; these are examples, not an efficacy
benchmark. CI results are available on the release commit.

See [validation scope](../validation.md) for inherited progress, citation,
multi-file TeX, and document-rendering limitations. This release does not claim
universal template support, live citation coverage, or scientific correctness.
