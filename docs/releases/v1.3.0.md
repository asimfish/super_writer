# v1.3.0: Evidence-Conditioned Writing Protocols

## Scope

- 130 language cards, up from 127, including all 78 reviewed upstream
  sentence-pattern cards. The three additions organize related work in embodied
  systems, RL regimes and world-model generation/control.
- 16 writer-facing protocols with 30 variants: sections, results paragraphs,
  table design, author responses and technical translation.
- Five adapted MIT LaTeX table skeletons for main results, ablation,
  generalization, efficiency and sensitivity.
- `writing_guide.py`: exact IDs and English/Chinese aliases, one complete
  protocol, optional variant, bounded Markdown/JSON output and explicit
  available/unbundled card pointers. No network, writes or compilation.
- A public worked application using existing, reproducible synthetic study
  results, plus bilingual documentation and activation expectations.

The six whole-paper blueprints, 11 profiles across eight conferences and eight
official-style compilation fixtures are unchanged. These inventories are not
additive counts of "top-conference templates."

## Design and Provenance

Required moves mean inspect applicable evidence, not manufacture results,
weaknesses, concessions or paragraphs. Choosing a variant never removes its
input requirements, domain overlays, warnings or verification checks. Budgets
too small for a complete protocol fail without output.

The [upstream audit](../../UPSTREAM.md#writing-resource-extension-2026-09-07)
pins Super Library data and licenses at one immutable revision. Review is
excluded because it belongs to a referee workflow. Attested collocations and
upstream executable orchestration remain excluded. Table headers are wrapped
and manual vertical spacing removed; placeholders are filled only from actual
project evidence, never by lookup. CC0 data and the full MIT table notice ship
together; missing license files block release building.

## Verification and Limits

See [validation](../validation.md) for reproducible commands and observed
results. New tests cover exact selection, complete checks under bounded output,
resource hashes/paths, licensing, installed offline use and synthetic fixtures.
Five tables compile in single-column and two-column full-width layouts, not
narrow columns or every possible filled table. Render data are explicitly
synthetic and are not writing examples or experimental evidence.

This release does not claim new official venue support, complete submission
compliance, a blind agent-writing evaluation or independent human assessment.
The raw table skeletons retain `SL_*` tokens and require actual input before
compilation. Current official venue instructions and visual inspection of the
filled paper remain necessary.
