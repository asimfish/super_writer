# v1.2.0: Venue Profiles and Evidence-Preserving Expression

## Scope

- 11 explicit 2026 venue/year/track/stage profiles across eight conferences.
- Eight pinned compilation fixtures, up from three: NeurIPS author-date/numeric,
  ACL, ECCV main and ECCV rebuttal extend the ICML/ICLR/CVPR set.
- Six contribution-specific argument blueprints and a scoped academic-expression
  contract: fidelity first, then removal of genuinely empty framing.
- 127 CC0 language cards with usage constraints and 37 discovery-source records;
  bounded offline lookup, Chinese aliases and reproducible import.
- PDF mechanical checks with snapshot hashes, font embedding, physical-page
  text bounds, optional log inspection and explicit total-page limits.
- Ten bilingual authored style examples, not a blind quality benchmark.

## Upstream Decisions

[The pinned audit](../../UPSTREAM.md#selective-integration-audit-2026-09-06)
records all five requested projects. PaperSpine's compared `src/skill/` tree did
not change from the already-integrated baseline; this is not a V5 runtime import.
PaperOrchestra's paper-excerpt prompts and limitation-suppression rule are not
imported. Natural-expression methods retain necessary uncertainty and required
disclosures. No agent-cache scan, key discovery or companion auto-install is added.

Original language records are CC0; software and adapted methods retain MIT
notices. The release builder refuses to distribute cards without their data
license and third-party notices. Linked papers retain their own rights.

## Behavior Changes

Style heuristics default to advisory. Explicit JSON
`humanize_enforce_heuristics: true` preserves optional threshold blocking;
matrix structure remains required. "No high-severity defect" is no longer an
error. A red/green comparison against v1.1.0 reproduced the old false rejection
of a complete low-severity audit of uniform technical prose.

Word checks recognize implicit ACL bibliography selection, LNCS numeric style
and explicit natbib numeric mode. They do not change official styles.
MiKTeX document builds pass `--disable-installer`; missing packages must be
resolved explicitly. An early local run revealed pre-existing MiKTeX auto-install
behavior and installed `eepic`; subsequent runs disable that behavior without
editing global configuration. The owned ECCV fixture's abstract overflow and
missing official wrapper color declaration were also found and corrected.
Linux CI exposed a false rejection of a normally hyphenated ACL fixture sentence;
the citation oracle now joins line-break hyphenation, with captured-text regression
cases that still reject wrong citation modes and inline spelling changes.
The document CI also explicitly installs `cm-super`. An isolated before/after
probe traced malformed ECCV ligature extraction to missing Type 1 font support;
the dependency fixes PDF text mapping without changing the prose or official style
and without weakening the XML checks.

## Verification and Limits

See [validation](../validation.md) for commands and observed results, and inspect
CI for the exact release commit. Mechanical checks, visual inspection and agent
behavior evaluation are separate evidence. This release does not claim an
independent blind writing evaluation or Word-client visual certification.

AAAI is explicitly **guide-only**: its official kit returned HTTP 403. No mirror
is substituted or counted as a successful build. All profiles are 2026 snapshots;
unknown years/stages require current official-source verification. A successful
fixture is not a full-paper page-limit, anonymity or submission certificate.
