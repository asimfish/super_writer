# Super Writer 1.1.0

Worked examples, evidence-bounded defaults and official-template regression
fixtures. The repository remains `super_writer`; invoke `$super-writer`.

## Added

- Three original AI-assisted educational examples: a reproducible kNN study,
  an elementary theory note, and a response to constructed reviewer comments.
  Each includes readable source, PDF, Word and an actual PDF preview.
- Public experiment code, all 20 computed measurements, aggregate results,
  an over-strong input draft and traceable writing decisions.
- Focused regressions for numeric/author-date citation modes, explicit budgets,
  complete citation-row checking, experiment arithmetic and archive boundaries.
- Pinned ICML 2026, ICLR 2026 and CVPR 2026 style compilation checks, alongside
  a CI document job. Official styles are downloaded for testing, not bundled.
- Reworked Chinese/English READMEs with examples first, contribution and security
  guides, issue/PR templates, and software citation metadata.

## Changed

- Preserve recognized official author-date styles in Word checks, including
  ICML 2026 and ICLR 2026. CVPR's numeric style is also recognized.
- Section count is advisory unless `max_sections` is set explicitly. Ignore
  TeX comments and appendix/reference sections when counting main sections.
- Citation collection size and recency are advisory unless
  `citation_enforce_heuristics=true`. Empty banks, malformed records and invalid
  configuration still fail. Validate every record, including rows beyond the
  collection target.
- Replace rigid word-frequency, claim-strength and section-length imitation
  targets with evidence-bounded rhetorical analysis.

## Validation and Limits

The local suite has 96 cases, up from 59, and passes on Python 3.10 and 3.14
with one environment-dependent PowerShell skip on each. The inherited 11-case
smoke suite, three document exports and three pinned template fixtures pass.
All six worked-example PDF pages were visually inspected.

See [validation scope and commands](../validation.md) and the CI run on this
release's commit. The examples are worked demonstrations, not blind agent
evaluations, accepted papers or evidence of improved acceptance rates. The
template fixtures do not certify full venue compliance. Word structure is
checked; rendering in every Word client is not certified.

## Download and Upgrade

`super_writer-v1.1.0-skill.zip` extracts to `super-writer/` and contains the
examples and documentation. Verify its matching `.sha256` file; per-file hashes
are in `MANIFEST.sha256`. Developer tools, tests and upstream style archives are
source-repository resources, not part of the installable payload.

The installer refuses an existing destination. Preserve local changes and move
the previous installation before installing the new version. Existing project
configs and output filenames remain compatible. Projects that deliberately want
the old hard collection/section budgets should set the explicit fields above.
