# Compression-First Writing

Excellent scientific prose is selective, not exhaustive. A revision should make
the reader's most important answer easier to recover under the same evidence and
a declared information budget. More detail, more caveats, and more protocol
labels are not improvements by themselves.

## One answer before many checks

Write one target answer before diagnosing style: what should a reader remember
after this section? Choose at most three priority criteria for one pass. Other
criteria may be assessed and explicitly deferred; they must not force unrelated
sentences into the draft.

## Delete before adding

Use this operation order unless evidence requires otherwise:

1. delete module inventories, generic setup, repeated referents, and defensive
   caveats whose scope is already explicit in the metric or noun;
2. merge sentences that serve the same reader question;
3. move a result next to the operation or comparison it evaluates;
4. add only the smallest clause needed to recover the target answer.

Every added clause must replace, merge, or make a required comparison explicit.
The proposal records what it keeps, removes or merges, and adds only if needed.

## Budget and acceptance

Compare the candidate with the source draft, not with an imaginary ideal. The
benchmark declares maximum words, sentences, allowed word-count change, and
added clauses. A candidate that exceeds these limits is rejected before taste or
fluency is discussed. If a longer draft is genuinely necessary, the author must
raise the budget explicitly and explain which evidence requires it.

The reviewer asks, in order:

- Is the target answer more recoverable?
- Did the revision preserve the supplied facts, conditions, and uncertainty?
- Is the result shorter or no longer without losing the decisive relation?
- Did any sentence survive only because a checklist asked for it?

Keep the original on a tie. A technically accurate but more verbose rewrite is a
regression when the original was already clear.
